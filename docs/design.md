# Design notes

This document records the ideas behind the project and the sources that influenced its visual design.

## Vision

The project began with a simple goal: bring the depth of Linux desktop customization to Windows. The idea took shape after seeing an [end4-pc](https://github.com/pctrade/end4-pC) showcase on Instagram.

## Pre-styled widgets

Many of the pre-styled widgets draw on designs from [end4-pC](https://github.com/pctrade/end4-pC) and its [presets repository](https://github.com/pctrade/end4-pCpresets/tree/main).

### `rainmeter-mond-clock-remake`

This widget is a remake of the clock from the Rainmeter theme [Mond](https://visualskins.com/skin/mond).

## Asset sources

- Some interface icons and SVG assets are sourced from [SVG Repo](https://www.svgrepo.com/).
- Some interface icons and SVG assets are recreated from [end4-pC](https://github.com/pctrade/end4-pC)'s [assets/material-shapes.js](https://github.com/pctrade/end4-pC/blob/main/modules/common/widgets/shapes/material-shapes.js)

## Future direction

- Grow the project beyond a desktop background and turn it into a replaceable Windows shell.
- Add stacked windows.
- Add a taskbar for application management.
